# 基于 ESP32/Arduino 的语音控制光闹钟灯 V1

> 状态：**立项完成，开发中** ｜ 创建：2026-08-19

## 项目简介

一款支持离线语音控制的光闹钟灯，具备时间显示、闹钟提醒、贪睡、日出模拟、灯光模式切换和断电记忆功能。主控为 ESP32，基于 Arduino / PlatformIO 框架开发。

## 功能特性

- OLED 显示当前时间（HH:MM:SS + 日期）
- 按键设置时间与闹钟
- DS3231 实时时钟，掉电保持
- WS2812 灯光控制（亮度 / 色温 / 渐变 / 呼吸）
- 日出模拟唤醒（闹钟前 N 分钟自动渐亮）
- 闹钟提醒 + 贪睡（默认 5 分钟）
- 离线语音命令（≥8 条）
- 参数掉电保存（ESP32 Preferences / NVS）

## 系统框图

```
离线语音模块
    ↓ UART 命令
ESP32 主控
    ├── WS2812 灯带/灯环：灯光/日出模拟
    ├── DS3231 RTC：时间管理
    ├── OLED SSD1306：时间/菜单显示
    ├── 按键 x4：设置/确认/加减
    ├── 蜂鸣器：闹钟声音
    └── NVS/Preferences：参数保存
```

## 语音命令表

| 语音 | 命令 ID | 动作 |
|---|---:|---|
| 打开灯 | 0x01 | 打开当前灯光模式 |
| 关闭灯 | 0x02 | 关闭灯光 |
| 夜灯模式 | 0x03 | 低亮度暖光 |
| 暖光模式 | 0x04 | 暖光 |
| 阅读模式 | 0x05 | 白光 |
| 关闭闹钟 | 0x06 | 关闭当前闹钟 |
| 再睡五分钟 | 0x07 | 进入贪睡 |
| 开始日出 | 0x08 | 手动启动日出模拟 |
