## Mentor 采购要求

1. 第一次不要买太多灯珠：灯环 16/24 颗，或灯带 30 颗；不要一上来 60/144 颗。（⚠️ 实际已购 60 LED 灯带，见电流估算与选型变更说明）
2. 语音模块必须确认：支持离线命令词、可自定词条、有串口输出命令、有商家资料 / 例程；不要买只能输出高低电平且无法扩展的封闭模块。（✅ SU-03T 符合）
3. 不要一开始买太贵的麦克风阵列（V1 不做复杂语音算法）。

## 电流估算

- 1 颗 WS2812 全白约 60 mA；**60 颗全白约 3.6 A**。
- 原定 5V 电源模块对 60 颗灯带严重不足，灯带必须**独立 5V 供电（建议 ≥4A）**或限制亮度与点亮颗数；5V 电源模块仅给主控 / OLED / 语音模块。

## 选型变更说明（2026-08-19）

- **主控**：由原「ESP32 DevKit V1」改为 **ESP32-S3 N16R8**。理由：S3 自带 8MB PSRAM + 16MB Flash，对后续离线语音词条缓存、UI 帧缓冲、音频缓冲更宽裕；原生 USB-CDC 方便烧录与串口调试；Arduino 框架（arduino-esp32）支持完善。PlatformIO board 选 `esp32-s3-devkitc-1`（或用 `board_build.flash_size` / `psram` 匹配 N16R8 变体）。
- **⚠️ 电平警告**：ESP32-S3 GPIO 为 **3.3V** 逻辑，而 WS2812 数据线（DIN）典型要求 **5V** 逻辑电平。短距离（<1 m）多数灯环可直接被 3.3V 驱动，但为稳定建议加 **74HCT245 电平转换**或确认灯环模块自带转换。该风险已写入 `docs/预研计划.md` 的 R1。
- **万用表**：由原泛称改为 **天宇 T21L**，具备电压 / 电流 / 通断 / 电容测量，覆盖 WS2812 供电电压、滤波电容容量检测。
- **其余元件**（灯 / RTC / OLED / 语音 / 按键 / 蜂鸣器 / 电源 / 辅材）按原清单采购中，到货后回填单价与链接。

## 选型变更说明（2026-08-19 晚 · 二次更新：用户确认实际型号）

- **显示**：确认使用 **0.96 寸 OLED**，驱动芯片 **SSD1315**（用户原始记录文字为「SSD131590」；SSD1315 为常见 I2C OLED 驱动，指令集与 SSD1306 兼容，I2C 地址通常 0x3C / 0x3D）。已将显示型号更新。
- **语音**：确认使用 **SU-03T** 离线语音模块，UART 输出命令词、可自定词条、有商家例程，符合 Mentor 采购要求第 2 条（非封闭模块）。命令协议待 M6 接 ESP32 时用串口助手确认。
- **灯带**：确认 **WS2812B 灯带 60 LED**（⚠️ 超出 Mentor 原建议「≤30 颗」）。全白约 **3.6 A**，原 5V 电源模块无力驱动，灯带必须**独立 5V 供电（≥4A）**或限制亮度；该风险写入电流估算与预研计划 R5。
- **电容**：实际购买 **100μF**（⚠️ 小于预研 R1 建议的 470~1000μF）。WS2812 电源端滤波偏小，实测若出现灯带闪烁 / 主控复位，需并联更大电容（470~1000μF）或缩短灯带长度。
- **电源**：确认使用 **5V 电源模块**，给主控 / OLED / 语音模块供电；灯带走独立 5V 供电，不与该模块共用。

## Day 2 决策（2026-08-20）

硬件在途，今日把两个"到货必翻车"的设计点拍板，写入 `docs/Day2任务清单.md`：

- **供电决策**：WS2812B 60 颗全白约 **3.6 A**，原 5V 电源模块带不动灯带。决策为**灯带独立 5V/≥4A 供电**，与主控 5V 模块**分开但共地**（GND 互联）。已新增「5V/≥4A 电源」待购项。
- **电平决策**：ESP32-S3 GPIO 为 **3.3V**，WS2812 DIN 典型要 5V。决策为 **WS2812 DIN 前加 74HCT245（或单路 BSS138 MOSFET）电平转换**，DIN 串 330Ω 电阻、灯带电源端并 100μF（实测闪烁/复位再加大到 470~1000μF）。已新增「电平转换模块」待购项。
- **引脚初稿**：I2C 用 GPIO 8/9，WS2812 DIN 用 GPIO 38，按键 10/11/12/13，蜂鸣器 GPIO 3，SU-03T 走 UART2（GPIO 16/17）。均为建议值，板到用万用表/丝印复核，避开 strapping 引脚（GPIO0/45/46）。见 Day2 任务清单引脚表。
