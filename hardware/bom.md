## Mentor 采购要求

1. 第一次不要买太多灯珠：灯环 16/24 颗，或灯带 30 颗；不要一上来 60/144 颗。
2. 语音模块必须确认：支持离线命令词、可自定词条、有串口输出命令、有商家资料 / 例程；不要买只能输出高低电平且无法扩展的封闭模块。
3. 不要一开始买太贵的麦克风阵列（V1 不做复杂语音算法）。

## 电流估算

- 1 颗 WS2812 全白约 60 mA；30 颗全白约 1.8 A。
- 5V/2A 供电对 30 颗灯带偏紧张，需留余量，必要时独立给灯供电。

## 选型变更说明（2026-08-19）

- **主控**：由原「ESP32 DevKit V1」改为 **ESP32-S3 N16R8**。理由：S3 自带 8MB PSRAM + 16MB Flash，对后续离线语音词条缓存、UI 帧缓冲、音频缓冲更宽裕；原生 USB-CDC 方便烧录与串口调试；Arduino 框架（arduino-esp32）支持完善。PlatformIO board 选 `esp32-s3-devkitc-1`（或用 `board_build.flash_size` / `psram` 匹配 N16R8 变体）。
- **⚠️ 电平警告**：ESP32-S3 GPIO 为 **3.3V** 逻辑，而 WS2812 数据线（DIN）典型要求 **5V** 逻辑电平。短距离（<1 m）多数灯环可直接被 3.3V 驱动，但为稳定建议加 **74HCT245 电平转换**或确认灯环模块自带转换。该风险已写入 `docs/预研计划.md` 的 R1。
- **万用表**：由原泛称改为 **天宇 T21L**，具备电压 / 电流 / 通断 / 电容测量，覆盖 WS2812 供电电压、滤波电容容量检测。
- **其余元件**（灯 / RTC / OLED / 语音 / 按键 / 蜂鸣器 / 电源 / 辅材）按原清单采购中，到货后回填单价与链接。
