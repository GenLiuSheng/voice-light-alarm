## 1. 供电两路线（到货先测再定）

> 决策逻辑：电压模块（3.3V/5V/12V）额定电流未知，**先实测带载能力**，再选路线。

| 路线 | 方案 | 适用条件 | 动作 |
|---|---|---|---|
| **A（优先试）** | 电压模块 5V 输出：主控 + OLED + SU-03T；灯带低亮度/≤16 颗 | 实测模块 5V **带载 ≥2A** | 先用 T21L 测 5V 输出空载/带载电压电流 |
| **B（稳妥）** | 灯带独立 5V/≥4A 电源；主控侧同上 | A 不达标或灯带全亮 | 灯带电源与主控**共地不共线** |

- 实测记录：A/B 判定结果写入本文件底部「实测记录」区。
- ⚠️ 60 颗全白 ≈ 3.6A，**任何路线下全亮都必须走独立电源**（B 或 A+限流）。

## 2. 连接总览

```text
                     3.3V
[电压模块 5V] ──────▶ ESP32-S3 5V/VIN ──▶ 板载 3.3V ──▶ OLED / DS3231 / SU-03T
      │                    │
      └── GND ─────────────┼───────────── 共地（所有设备）
                           │
[灯带电源 5V/≥4A] ──────▶ WS2812B VCC
      └── GND ─────────────┘（与主控共地，独立供电）
```

## 3. 引脚接线表（初稿，待板复核）

| 设备 | 信号 | ESP32-S3 | 对端 | 备注 |
|---|---|---|---|---|
| WS2812B | DIN | GPIO38 → 330Ω → 电平转换 → DIN | 灯带 | 3.3V→5V；VCC 并 100μF（闪烁/复位加 470~1000μF） |
| OLED (SSD1315) | SDA | GPIO8 | OLED SDA | I2C 0x3C |
| OLED | SCL | GPIO9 | OLED SCL | 总线并联，4.7kΩ 上拉到 3.3V |
| DS3231 | SDA | GPIO8（共用总线） | DS3231 SDA | I2C 0x68 |
| DS3231 | SCL | GPIO9（共用总线） | DS3231 SCL | 同上 |
| 按键 MODE | IO | GPIO10 | 按键一端 | 另一端 GND，内部上拉 + 消抖 |
| 按键 ADD | IO | GPIO11 | 按键一端 | 同上 |
| 按键 SUB | IO | GPIO12 | 按键一端 | 同上 |
| 按键 OK | IO | GPIO13 | 按键一端 | 同上 |
| 蜂鸣器 | IO | GPIO3 ⚠️ | 蜂鸣器 | strapping 引脚（JTAG 选择），**待复核**：影响启动则换 GPIO5/14/15 |
| SU-03T | UART2 RX | GPIO16 | 模块 TX | 9600 波特率待实测确认 |
| SU-03T | UART2 TX | GPIO17 | 模块 RX | 与模块共地 |

> strapping 引脚避让：GPIO0 / 3 / 45 / 46 上电时序敏感；GPIO19/20 为 USB；N16R8 的 GPIO26~37 部分被 Flash/PSRAM 占用（33~37 为 octal PSRAM），故数据口选 38、I2C 选 8/9、按键选 10~13。
> 复核动作：板到后用 T21L 通断档对丝印逐脚核对，再改 `src/config.h` 定稿。

## 4. 接线顺序（到货第一天，从简到繁）

1. 只接 ESP32-S3 + USB：Blink 例程通过 → 烧录链路 OK
2. 接 WS2812 单颗：红色 10% → 验证供电/共地/电平
3. 接 OLED + DS3231：I2C Scanner 扫到 0x3C + 0x68
4. 接 4 按键：串口打印事件
5. 接 SU-03T：先 USB-TTL 串口助手确认协议，再接 ESP32
