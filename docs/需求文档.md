## 1. 功能需求（FR）

### FR1 时间显示

- 系统应在 OLED 上显示当前时间，格式：`HH:MM:SS`
- 同时显示日期，格式：`YYYY-MM-DD`
- 显示刷新应无明显卡顿（≥1 Hz 更新，且不阻塞其他任务）

### FR2 时间设置

- 用户可通过按键设置：年 / 月 / 日 / 时 / 分 / 秒
- 设置过程中 OLED 应高亮当前正在编辑的项
- 设置完成后写回 DS3231，并立即生效

### FR3 闹钟设置

- 用户可设置：闹钟时、闹钟分、闹钟开关（开 / 关）
- 可设置日出提前时间，选项：**10 / 20 / 30 分钟**（默认 20）
- 闹钟参数掉电保存（见 FR9）

### FR4 闹钟触发

- 当「当前时间 == 闹钟时间」且闹钟开启时，进入闹钟提醒状态
- 触发表现：
  - WS2812 灯光高亮 / 闪烁
  - 蜂鸣器鸣叫
  - OLED 显示 `ALARM`
- 同一分钟只触发一次（防重复触发）

### FR5 贪睡（Snooze）

- 用户可通过按键或语音进入贪睡，默认 **5 分钟**
- 贪睡期间：停止蜂鸣、灯光降为低亮度或关闭
- 5 分钟后再次触发闹钟（回到 FR4 状态）
- 可多次贪睡（每次重新计 5 分钟）

### FR6 日出模拟（Sunrise）

- 在闹钟时间前 N 分钟（由 FR3 设定）自动进入 SUNRISE 状态
- 灯光从暗暖色随时间逐渐变亮、色温由暖转白
- 到闹钟时间时自动转入 FR4 提醒状态
- 渐变应平滑（肉眼无明显跳变）

### FR7 灯光模式

至少支持 4 种模式：

| 模式 | 说明 |
|---|---|
| 关闭 | 全灭 |
| 夜灯 | 低亮度暖光（约 5%~15%） |
| 暖光 | 中等亮度暖白 |
| 阅读 / 白光 | 高亮度冷白 |

- 亮度应可分级调节（建议 ≥5 级）
- 支持呼吸 / 渐变等基础动效（用于夜灯与测试）

### FR8 离线语音控制

至少支持 8 条离线命令（UART 文本 / ID 输出）：

| 语音 | 命令 ID | 动作 |
|---|---:|---|
| 打开灯 | 0x01 | 打开当前灯光模式 |
| 关闭灯 | 0x02 | 关闭灯光 |
| 夜灯模式 | 0x03 | 低亮度暖光 |
| 暖光模式 | 0x04 | 暖光 |
| 阅读模式 | 0x05 | 白光 |
| 关闭闹钟 | 0x06 | 关闭当前闹钟 |
| 再睡五分钟 | 0x07 | 进入贪睡 |
| 开始日出 | 0x08 | 手动启动日出模拟 |

- 安静环境、距离 50 cm~1 m，主要命令应可稳定识别并执行
- 命令响应时间 < 1 s（从模块输出到动作生效）

### FR9 参数掉电保存

以下参数掉电不丢失（ESP32 Preferences / NVS）：

- 闹钟时间（时 / 分）
- 闹钟开关
- 日出提前时间
- 当前灯光模式
- 亮度等级

## 2. 非功能需求（NFR）

| 编号 | 类型 | 要求 |
|---|---|---|
| NFR1 | 实时性 | 按键响应 < 200 ms |
| NFR2 | 闹钟精度 | 触发误差 < 1 s（相对 RTC） |
| NFR3 | 稳定性 | 连续运行 24 h 不复位 |
| NFR4 | 语音响应 | 命令响应 < 1 s |
| NFR5 | 灯光 | 渐变无明显跳变 |
| NFR6 | 供电 | 5V/2A 可支持 ≤30 颗 WS2812 |
| NFR7 | 可维护性 | 代码模块化、有注释、状态机清晰 |
| NFR8 | 可测试性 | 每个模块可独立例程测试 |
| NFR9 | 文档 | README / 接线图 / 测试报告 / 演示视频齐全 |
