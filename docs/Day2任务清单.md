- [ ] **路线 A（优先，先测再说）**：到货后用万用表测模块 5V 输出带载能力 → 若 ≥2A，可供电主控 + OLED + SU-03T，灯带低亮度/少颗数运行
- [ ] **路线 B（稳妥）**：灯带**独立 5V/≥4A 电源**（BOM 已列待购），与主控 5V 模块/电平转换模块**共地不共线**
- [ ] 结论写进 `hardware/wiring.md`（今天先建文件占位，板到填图）
- [ ] 确认：DIN 串 **330Ω**（待购）、灯带电源端并 **100μF**（已购，闪烁/复位再加大到 470~1000μF）

## 五、建议引脚分配（初稿，待板复核）

> 原则：避开 S3 strapping 引脚（GPIO0/45/46 等）；任意 GPIO 可经矩阵做 I2C。

| 设备 | 建议 ESP32-S3 引脚 | 备注 |
|---|---|---|
| OLED SDA | GPIO 8 | I2C 0x3C/0x3D（SSD1315 兼容 SSD1306） |
| OLED SCL | GPIO 9 | |
| DS3231 SDA | GPIO 8 | 与 OLED 同 I2C 总线 |
| DS3231 SCL | GPIO 9 | |
| WS2812 DIN | GPIO 38 | 经电平转换模块 3.3V→5V；串 330Ω |
| 按键 MODE | GPIO 10 | 内部上拉 + 软件消抖 |
| 按键 ADD | GPIO 11 | |
| 按键 SUB | GPIO 12 | |
| 按键 OK | GPIO 13 | |
| 蜂鸣器 | GPIO 3 | 有源蜂鸣器，触发极性看模块 |
| SU-03T TX → ESP32 RX | GPIO 16 | UART2_RX，波特率见商家资料 |
| SU-03T RX ← ESP32 TX | GPIO 17 | UART2_TX |
| SU-03T GND | ESP32 GND | **必须共地** |

> ⚠️ 建议值，板到后用万用表/丝印确认无冲突（尤其避开已接 PSRAM/Flash 的引脚）。

## 六、SU-03T 协议预研要点（今日只收集，不臆测）

- 离线语音模块，UART 输出识别到的命令字
- 默认波特率多为 **9600**（以商家资料为准）
- 词条用厂家配置工具烧录，可自定
- 帧格式 / 校验 / 命令字编号 **M6 接 ESP32 前用电脑串口助手实测确认**
- 8 条命令映射（对齐需求 FR8）：

| 语音 | 命令 ID | 动作 |
|---|---:|---|
| 打开灯 | 0x01 | 打开当前灯光模式 |
| 关闭灯 | 0x02 | 关闭灯光 |
| 夜灯模式 | 0x03 | 低亮度暖光 |
| 暖光模式 | 0x04 | 暖光 |
| 阅读模式 | 0x05 | 白光 |
| 关闭闹钟 | 0x06 | 关闭当前闹钟 |
| 再睡五分钟 | 0x07 | 进入贪睡 |
| 开始日出 | 0x08 | 手动启动日出模拟 |
