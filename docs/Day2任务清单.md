## 三、P0 必做（今日核心，5 项）

### 1. 确认 Arduino IDE 已安装并正确配置
> 注：Arduino IDE 2.x 是免费软件，没有"激活码"；这里的"正确激活"理解为**正确配置到能开发 ESP32-S3**。

- [ ] 下载安装 Arduino IDE 2.x
- [ ] 文件 → 首选项 → 附加开发板网址加入 ESP32 包：
  `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`
- [ ] 工具 → 开发板管理器 → 搜 `esp32` → 安装（建议 3.x 版本，支持 S3）
- [ ] 安装 USB 转串驱动：**先确认板子丝印是 CH340 还是 CP210x**（ESP32-S3 DevKitC-1 多为 CH343/原生 USB-CDC）。驱动装错会找不到端口
- [ ] 选板 `ESP32S3 Dev Module`，其余默认，**编译一次空 Blink**（无板也能 Compile，验证工具链）
- [ ] 完成后截图 + 本地 commit：`chore: Arduino IDE 配置 ESP32-S3 完成`

### 2. 验证 PlatformIO 工程可编译（板到前唯一能验证工具链的手段）
- [ ] 打开 `platformio.ini`（已建好，`board = esp32-s3-devkitc-1` + PSRAM 开启 + 4 个库）
- [ ] VS Code → PlatformIO → Build，确认 `src/` 六模块骨架 + `main.cpp` 能编译通过
- [ ] 若编译报错（库版本/PSRAM/分区），今天修掉，别留到板到了再卡
- [ ] 完成后截图 + commit：`build: PlatformIO 工程编译通过`

### 3. 拍板 60 灯带供电方案（设计决策，必须今天定）
> 背景：WS2812B 60 颗全白约 **3.6 A**，你已有的 5V 电源模块带不动灯带。

- [ ] **决策：灯带独立 5V 供电（建议 ≥4A），与主控 5V 模块分开**
  - ESP32 / OLED / SU-03T / DS3231 由 5V 模块供电
  - WS2812B 灯带由独立的 5V/≥4A 电源供电，**两者 GND 必须相连（共地）**
- [ ] 把"独立 5V/≥4A 灯带电源"加入 bom 待购项
- [ ] 写入 `hardware/wiring.md`（今日可先建文件占位，板到填图）

### 4. 拍板 WS2812 电平转换方案（设计决策，补一件物料）
> 背景：ESP32-S3 GPIO 是 **3.3V**，WS2812 DIN 典型要 5V 逻辑。短距离常可直接驱动，但为稳必须加电平转换。

- [ ] **决策：WS2812 DIN 前加 74HCT245（或单路 BSS138 MOSFET）电平转换**
- [ ] 把"电平转换模块（74HCT245 / BSS138）"加入 bom 待购项
- [ ] 同时确认：DIN 串 **330Ω** 电阻（已在待购）、灯带电源端并 **100μF**（已购，实测若闪烁再加大到 470~1000μF）

### 5. 产出 ESP32-S3 引脚分配初稿 + SU-03T 协议要点（设计决策）

## 五、建议引脚分配（初稿，待板复核）

> 原则：避开 S3 的 strapping 引脚（GPIO0/45/46 等，影响启动）；任意 GPIO 都可通过矩阵做 I2C。

| 设备 | 建议 ESP32-S3 引脚 | 备注 |
|---|---|---|
| OLED SDA | GPIO 8 | I2C 0x3C/0x3D（SSD1315 兼容 SSD1306） |
| OLED SCL | GPIO 9 | |
| DS3231 SDA | GPIO 8 | 与 OLED 同 I2C 总线 |
| DS3231 SCL | GPIO 9 | |
| WS2812 DIN | GPIO 38 | 经 74HCT245 升到 5V；串 330Ω |
| 按键 MODE | GPIO 10 | 内部上拉 + 软件消抖 |
| 按键 ADD | GPIO 11 | |
| 按键 SUB | GPIO 12 | |
| 按键 OK | GPIO 13 | |
| 蜂鸣器 | GPIO 3 | 有源蜂鸣器，低电平/高电平触发看模块 |
| SU-03T TX → ESP32 RX | GPIO 16 | UART2_RX，默认波特率见商家资料 |
| SU-03T RX ← ESP32 TX | GPIO 17 | UART2_TX |
| SU-03T GND | ESP32 GND | **必须共地** |

> ⚠️ 此表为建议值，板到后用万用表/丝印确认每个 GPIO 是否冲突（尤其避开已接 PSRAM/Flash 的引脚）。

## 六、SU-03T 协议预研要点（今日只收集，不臆测）

- 离线语音模块，UART 输出识别到的命令字
- 默认波特率多为 **9600**（以商家资料为准）
- 词条用厂家配置工具（如「智能公元」/ SU-03T 专用工具）烧录，可自定
- 串口帧格式、校验位、命令字编号 **M6 接 ESP32 前用电脑串口助手实测确认**
- 8 条命令映射（对齐需求 FR8）：

| 语音 | 命令 ID | 动作 |
|---|---:|---|
| 打开灯 | 0x01 | 打开当前灯光模式 |
| 关闭灯 | 0x02 | 关闭灯光 |
| 夜灯模式 | 0x03 | 低亮度暖光 |
| 暖光模式 | 0x04 | 暖光 |
| 阅读模式 | 0x05 | 白光 |
| 关闭闹钟 | 0x06 | 关闭当前闹钟 |
| 再睡五分钟 | 0x07 | 进入贪睡 |
| 开始日出 | 0x08 | 手动启动日出模拟 |
