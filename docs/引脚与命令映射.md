## 1. 引脚分配（初稿）

| 设备 | 信号 | GPIO | 备注 |
|---|---|---|---|
| WS2812B | DIN | 38 | 经电平转换 + 串 330Ω |
| OLED (SSD1315) | SDA / SCL | 8 / 9 | I2C 0x3C |
| DS3231 | SDA / SCL | 8 / 9 | 与 OLED 共用总线，0x68 |
| 按键 MODE | IO | 10 | 内部上拉 + 消抖 |
| 按键 ADD | IO | 11 | 同上 |
| 按键 SUB | IO | 12 | 同上 |
| 按键 OK | IO | 13 | 同上 |
| 蜂鸣器 | IO | 3 ⚠️ | strapping 引脚，待复核（备选 5/14/15） |
| SU-03T | UART2 RX | 16 | 接模块 TX |
| SU-03T | UART2 TX | 17 | 接模块 RX |

**避让说明**：GPIO0/3/45/46 为 strapping；GPIO19/20 为 USB；GPIO33~37 被 N16R8 octal PSRAM 占用。板到后用 T21L 通断档复核丝印，再同步修改 `src/config.h`。

## 2. SU-03T 命令映射（8 条）

> 词条需先在 SU-03T 配置工具（商家提供）中录入并烧录到模块；模块 UART 输出命令 ID 的**具体帧格式**（如 `FD xx xx xx xx FC` 校验包）待 M6 用串口助手实测确认。下方 ID 与 `src/app_state.h` 的 `VoiceCmd` 枚举一致。

| # | 语音词条 | 命令 ID | 动作 | 对应需求 |
|---|---|---|---|---|
| 1 | 打开灯 | 0x01 | 打开当前灯光模式 | FR8 / FR7 |
| 2 | 关闭灯 | 0x02 | 关闭灯光 | FR8 / FR7 |
| 3 | 夜灯模式 | 0x03 | 低亮度暖光 | FR8 / FR7 |
| 4 | 暖光模式 | 0x04 | 暖光 | FR8 / FR7 |
| 5 | 阅读模式 | 0x05 | 白光 | FR8 / FR7 |
| 6 | 关闭闹钟 | 0x06 | 关闭当前闹钟 | FR8 / FR5 |
| 7 | 再睡五分钟 | 0x07 | 进入贪睡 5 分钟 | FR8 / FR5 |
| 8 | 开始日出 | 0x08 | 手动启动日出模拟 | FR8 / FR6 |

**ESP32 端解析约定**（`voice_ctrl` 实现时遵守）：
1. 用 `HardwareSerial`（UART2）非阻塞读取，缓冲区 + 超时解析；
2. 解析到 ID 后置 pending，`main.cpp` 每轮 loop 取走消费；
3. 未知帧 / 校验失败 → `VOICE_UNKNOWN`，不动作；
4. 波特率默认 9600，M6 实测后如需变更改 `config.h` 的 `VOICE_UART_BAUD`。

**配置流程（板到后）**：
1. SU-03T 先不接 ESP32，用 USB-TTL 接电脑串口助手；
2. 确认波特率与输出格式（文本 or 16 进制包）；
3. 按上表录入 8 个词条并烧录；
4. 每条命令测 10~20 次记录成功率（写入 docs/问题记录.md）。
