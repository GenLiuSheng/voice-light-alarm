### 5. 安装 Arduino IDE + 跑通 ESP32 Blink

- 下载安装 [Arduino IDE 2.x](https://www.arduino.cc/en/software)
- 文件 → 首选项 → 附加开发板管理器网址 → 加入 ESP32 包 URL：
  `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`
- 工具 → 开发板 → 开发板管理器 → 搜 `esp32` → 安装
- 安装 USB 转串驱动（看板子丝印：CH340 装 CH340 驱动，CP210x 装 CP210x 驱动）
- 工具 → 板选 `ESP32 Dev Module` → 选端口 → 烧录 `Blink`
- 验证：板载 LED 1 秒闪
- 烧录成功后截图 + commit：`feat: ESP32 Blink 跑通`
