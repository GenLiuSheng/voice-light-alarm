# 项目立项书

> 版本：V1
> 创建日期：2026-08-19
> 角色：独立开发（大三实习生，少量 C / STM32 基础）
> 开发框架：Arduino（ESP32 平台），后续迁移至 PlatformIO

## 项目名称

**基于 ESP32/Arduino 的语音控制光闹钟灯 V1**

> 说明：Arduino 是开发框架而非芯片。主控实际为 ESP32，使用 Arduino 框架开发。

## 项目背景

普通闹钟主要依靠声音唤醒，体验较生硬。本项目希望通过灯光渐变模拟日出，并结合离线语音控制，实现更自然的床头唤醒设备。

## 项目目标

完成一款可演示、可测试、可写入简历的嵌入式作品，支持：

- 时间显示
- 闹钟提醒
- 贪睡
- 日出模拟
- 灯光模式切换
- 离线语音控制

## 目标用户

学生、宿舍用户、作息不规律人群、对普通闹钟声音敏感人群。

## 核心功能

1. OLED 显示当前时间（HH:MM:SS + YYYY-MM-DD）
2. 按键设置时间与闹钟
3. DS3231 掉电保持时间
4. WS2812 灯光控制（亮度 / 色温 / 渐变）
5. 日出模拟唤醒（闹钟前 N 分钟自动渐亮）
6. 闹钟提醒与贪睡（默认 5 分钟）
7. 离线语音命令控制（≥8 条命令）
8. 参数掉电保存（闹钟时间、开关、日出提前量、灯光模式、亮度）

## 非目标（V1 暂不做）

1. 不做在线语音识别
2. 不做自然语言理解
3. 不做手机 App
4. 不做云端账号系统
5. 不做复杂音箱结构
6. 不做电池供电低功耗
7. 不做定制 PCB
8. 不做复杂外观
9. 不做音乐播放
10. 不做睡眠监测算法

> 以上可放到 V2 / V3。

## 成功标准

### 功能验收

1. OLED 能显示当前时间
2. 时间可通过按键设置
3. RTC 掉电后时间可保持
4. 可设置闹钟时间
5. 闹钟到点能触发灯光 / 蜂鸣器
6. 支持贪睡 5 分钟
7. WS2812 能显示多种灯光模式
8. 支持日出模拟
9. 离线语音模块能控制基础功能
10. 断电后闹钟设置不丢失

### 非功能验收

1. 系统连续运行 24 小时不复位
2. 闹钟触发误差小于 1 秒
3. 灯光渐变肉眼基本平滑
4. 语音命令响应时间小于 1 秒
5. 安静环境下基础命令识别率可接受
6. 代码有模块划分，不是全塞在 `loop()`
7. 有 README、接线图、测试记录、演示视频

## 计划周期

6～8 周（可压缩到 4～5 周，但每天投入需更多）

## 风险

| 编号 | 风险 | 等级 | 对策 |
|---|---|---|---|
| R1 | WS2812 驱动不稳定（颜色错乱 / 闪烁 / 供电不足） | 高 | 独立 5V 供电、共地、电源端加 470~1000μF 电容、DIN 串 330Ω 电阻、先低亮度测试 |
| R2 | I2C 设备冲突 / 识别失败 | 中 | 先写 I2C Scanner，单独测 DS3231 与 OLED，再并联；确认地址 0x68 / 0x3C |
| R3 | 语音模块识别率不稳 / 误触发 | 中 | 先用串口助手确认输出协议，固定测试距离与环境，每命令测 10~20 次 |
| R4 | 系统卡死 / 闹钟不准 | 高 | 禁用长 `delay()`，用 `millis()` 非阻塞定时 + 状态机，串口接收用缓冲 |
| R5 | 供电不足导致灯光异常 | 中 | 5V/2A，灯珠先 ≤30 颗，全白电流约 30×60mA=1.8A，留余量 |

## 硬件方案（V1 决策）

- 主控：**ESP32 DevKit V1**（Arduino / PlatformIO 框架，资源强、库丰富、后续可加 WiFi / 网络校时）
- 灯：**WS2812B** 灯环 16/24 颗 或 灯带 30 颗
- 时钟：**DS3231** RTC（掉电保持）
- 显示：**0.96 寸 SSD1306 OLED**（I2C）
- 语音：**支持 UART 输出的离线语音模块**（可自定词条）
- 按键：轻触按键 4 个（MODE / ADD / SUB / OK）
- 蜂鸣器：有源蜂鸣器
- 电源：5V / 2A
- 辅助：面包板、杜邦线、1000μF 电容、330Ω 电阻、万用表、USB 数据线、CR2032 纽扣电池

## 模块划分（代码骨架）

```
light_ctrl   灯光控制
clock_ctrl   时间管理
alarm_ctrl   闹钟 / 贪睡 / 日出逻辑
voice_ctrl   语音命令接收与解析
ui_ctrl      OLED 显示与按键
storage_ctrl 参数保存
```
