## 总原则

1. **先跑模块，再整合**：WS2812 → OLED → DS3231 → 按键 → 闹钟 → 日出 → 语音 → 整合
2. **每个模块先有独立例程**：放 `examples/01_xxx` 下，不一开始写最终工程
3. **禁用长 `delay()`**：统一 `millis()` + 状态机，串口接收用缓冲

## 风险 1：WS2812 驱动不稳定（R1，高）

### 表现
颜色错乱、闪烁、灯乱跳、只亮一部分、全白 / 全红。

### 根因排查
- 电源不足 / 未共地
- 数据线过长 / 未串电阻 / 电源纹波
- **ESP32-S3 GPIO 为 3.3V 逻辑，WS2812 DIN 典型要 5V**（重点！）
- 颜色顺序不是 RGB 而是 GRB

### 预研任务
| 步骤 | 验证目标 | 通过标准 |
|---|---|---|
| 1. 点亮 1 颗红色 @10% | 供电 / 共地基本正确 | 显示稳定红 |
| 2. 点亮 16 颗 RGB | 数据链正常 | 全彩可控 |
| 3. 全亮 50% 白光 | 电流与电源 | 5V/2A 不跌落 |
| 4. 全亮 100% 白光 | 极限电流 | 不复位、不闪烁 |
| 5. 呼吸 / 渐变 | 动效平滑 | 肉眼无跳变 |

### 对策（落地）
- 独立 5V 给灯；ESP32 GND ↔ 灯 GND **必须共地**
- 灯 VCC↔GND 并 **1000μF** 电容；DIN 前串 **330Ω**
- **电平转换**：3.3V→5V 用 74HCT245（或确认灯环自带）；S3 直接驱短灯环可试，但量产前必加转换
- 先低亮度（10%）再逐步拉高，记录电流

## 风险 2：I2C 设备识别失败（R2，中）

### 表现
OLED 不显示、DS3231 读不到、I2C 扫描无设备。

### 预研任务
| 步骤 | 验证目标 | 通过标准 |
|---|---|---|
| 1. I2C Scanner | 确认总线能扫到设备 | 找到 0x68（DS3231）、0x3C/0x3D（OLED） |
| 2. 单独测 DS3231 | 读 / 写时间 | 正常 |
| 3. 单独测 OLED | 显示 Hello | 正常 |
| 4. 并联测 | 两设备共存 | 均正常 |

### 注意（ESP32-S3 差异）
- **ESP32-S3 默认 I2C 引脚与 ESP32 不同**（ESP32 常用 GPIO21/22；S3 需查数据手册，常为 GPIO8/GPIO9 或软件映射）。PlatformIO 中用 `Wire.begin(SDA, SCL)` 显式指定。
- 上拉 4.7kΩ 到 3.3V（S3 是 3.3V IO）。

## 风险 3：语音模块不稳定（R3，中）

### 表现
识别率低、误触发、串口无输出、命令格式不清。

### 预研任务（**先不接 ESP32**）
1. 语音模块 → USB-TTL → 电脑串口助手
2. 确认波特率、命令格式（文本 or 16 进制 ID）
3. 固定测试距离（50 cm / 1 m）、固定安静环境
4. 每条命令测 10~20 次，记录成功率与响应时间

### 对策
- 模块必须支持 UART 输出 + 自定词条（采购已按此要求）
- ESP32 端用 `HardwareSerial` 独立 UART 接收，缓冲区 + 超时解析
- 处理未知命令、过滤误触发（如置信度阈值）

---

## 风险 4：系统卡死 / 闹钟不准（R4，高）

### 表现
按键无响应、显示不刷新、闹钟错过、蜂鸣器长响。

### 预研任务
- 系统同时运行 WS2812 + OLED + 按键时，按键响应不被灯效阻塞
- 闹钟判断基于 RTC 秒更新，非 `delay` 累计

### 对策
- 状态机：`NORMAL / SET_TIME / SET_ALARM / SUNRISE / ALARM / SNOOZE / NIGHT / OFF`
- `loop()` 只调度，复杂逻辑进模块 `update()`
- 所有定时用 `millis()`；串口接收中断 / 缓冲

## ESP32-S3 专项（本次选型新增，必做）

| 项目 | 要点 | 验证 |
|---|---|---|
| 电平 | GPIO 3.3V，WS2812 DIN 需 5V → 电平转换 | 见 R1 |
| I2C 引脚 | 默认引脚与 ESP32 不同，需查手册并显式指定 | 见 R2 |
| PSRAM | 8MB，Arduino 下需开启：`board_build.psram = enable` | 编译通过、可 malloc 大缓冲 |
| 烧录 | 原生 USB-CDC，PlatformIO 选 `esp32-s3-devkitc-1` | Blink 烧录成功 |
| Flash | 16MB，注意 `flash_size` 配置与分区表 | 固件可写 |

## 到货第一天必做 5 件事（M1 起点）

1. 先只接 ESP32-S3，跑 PlatformIO Blink（板载 LED / 点一个 GPIO）
2. 接 WS2812（单颗）→ 验证 3.3V 能否驱动，不能则加电平转换
3. I2C Scanner 扫 DS3231 + OLED
4. 按键 4 个串口打印事件
5. 语音模块 USB-TTL 串口助手确认输出协议
